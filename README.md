# 매일 성경 낭독

매일 읽을 성경 본문을 띄워 주고, 소리 내어 읽으면 읽은 곳을 따라가며 표시해 주는 웹앱입니다.
휴대폰 브라우저에서 열어 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 할 수 있는 것

- **날마다 바뀌는 본문**: 고른 읽기표에 따라 오늘 읽을 본문이 열립니다.
  - 1년 1독: 성경 전체를 365일 동안, 하루 3~4장 (하루 분량이 고르게 나뉘어 있어요)
  - 맥체인: 하루 4곳(가족 1·2, 개인 1·2). 1년에 구약은 한 번, 신약과 시편은 두 번 읽습니다. 원래 표처럼 날짜에 맞춰 1월 1일부터 시작합니다(처음부터 읽으려면 시작일을 오늘로 바꾸세요).
  - 진도 + 시가서: 순서대로 읽는 진도(성경 전체·구약·신약, 시가서 빼고)와 시가서(욥기~아가·시편·잠언·시편과 잠언)를 각각 하루 몇 장 읽을지 고릅니다. 시가서는 다 읽으면 처음부터 다시 돕니다. 분량을 바꿔도 두 진도 모두 읽던 곳에서 이어집니다.
  - 신약 260일: 마태복음부터 하루 1장
  - 시편·잠언 181일: 하루 1장
  - 하루 한 장: 창세기 1장부터 1,189일
- **소리 내어 읽으면 따라가기**: 마이크 버튼을 누르고 읽으면 읽은 어절의 색이 바뀌고, 다음에 읽을 어절에 표시가 붙습니다. 화면도 읽는 곳을 따라 내려갑니다.
- **자동 기록**: 본문의 90% 이상을 읽으면 '다 읽음'으로 기록되고, 연속으로 읽은 날 수와 최근 5주 달력에 표시됩니다.
- **껐다 켜도 이어서**: 앱을 다시 열면 마지막으로 읽은 곳 바로 다음, 새로 읽을 어절로 화면이 옮겨집니다. 그 본문을 다 읽었으면 다음 본문이 열립니다. 계획보다 앞서거나 늦으면 "계획상 오늘은 N일째"라고 알려 줍니다.
- 절 번호를 누르면 그 절부터 이어서 듣습니다. '전날'/'다음날'로 다른 본문을 보다가 '이어 읽을 곳으로'를 누르면 돌아옵니다.
- 글자 크기 조절과 어두운 화면(다크 모드)을 지원합니다.
- 음성 인식이 안 되는 환경에서는 읽고 나서 '다 읽음'을 눌러 직접 기록할 수 있습니다.

## 여는 방법

마이크는 보안 주소(**https**)에서만 쓸 수 있습니다. 파일을 그냥 더블클릭해서 열면 음성 인식이 되지 않을 수 있으니, 아래 방법 중 하나로 인터넷 주소를 만들어 주세요.

### 방법 1. GitHub Pages (무료, 저장소를 공개로 바꿔야 함)

무료 계정에서는 비공개 저장소에 GitHub Pages를 켤 수 없습니다.

1. 저장소의 **Settings → General → 맨 아래 Danger Zone → Change visibility → Public**
2. **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**로, Branch를 **main**과 **/(root)** 로 고른 뒤 **Save**
   (이 작업이 아직 main에 합쳐지지 않았다면 브랜치를 `ccr-e761be61-nr84db`로 고르면 됩니다.)
3. 1~2분 뒤 `https://jjangguss-prog.github.io/desktop-tutorial/` 로 열립니다.

### 방법 2. Netlify Drop (저장소를 비공개로 둘 때)

1. GitHub에서 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. <https://app.netlify.com/drop> 에 압축을 푼 폴더를 끌어다 놓으면 https 주소가 바로 만들어집니다.

### 휴대폰에서

- **안드로이드**: Chrome으로 열고 메뉴(⋮) → **홈 화면에 추가**
- **아이폰·아이패드**: Safari로 열고 공유 버튼 → **홈 화면에 추가**
- 아이폰에서 음성 인식이 안 되면 **설정 → 일반 → 키보드 → 받아쓰기 활성화**를 켜 주세요. 홈 화면에 추가한 앱에서 안 되면 Safari에서 직접 열어 보세요.
- 카카오톡에서 링크를 누르면 앱 안의 브라우저로 열리는데, 여기서는 음성 인식이 안 될 수 있습니다. 오른쪽 위 메뉴에서 **다른 브라우저로 열기**를 눌러 주세요.

## 쓰는 법

1. 처음 연 날이 읽기표의 1일째가 됩니다. 오른쪽 위 설정 버튼에서 읽기표와 시작일을 바꿀 수 있습니다. 시작일을 바꾸면 그 날짜로 따진 오늘 본문부터 다시 이어 읽습니다.
2. 아래의 **소리 내어 읽기**를 누르고, 처음 한 번은 마이크 사용을 허용해 주세요.
3. 1절부터 평소처럼 소리 내어 읽습니다. 읽은 곳은 연한 초록빛으로 바뀝니다.
4. 놓친 곳이 있으면 지금 읽고 있는 절의 번호를 눌러 주세요. 그 절부터 다시 따라갑니다.
5. 끝까지 읽으면 지면 위의 책갈피 끈이 내려오며 '읽음'이 표시되고, 오늘 날짜에 기록됩니다.

## 알아 둘 점

- 음성 인식은 브라우저에 들어 있는 기능(Web Speech API)을 씁니다. Chrome은 Google, Safari는 Apple의 서버에서 음성을 글자로 바꾸므로 인터넷 연결이 필요합니다.
- 읽은 기록은 **이 기기의 브라우저에만** 저장됩니다. 다른 기기와 함께 쓰이지 않고, 브라우저 데이터를 지우면 사라집니다.
- 목소리의 주인이 누구인지는 구별하지 않습니다. 본문을 소리 내어 읽었는지를 확인합니다.
- 인식기는 옛 표기(예: "다닐찌라도"→"다닐지라도")나 이름, 낯선 낱말을 자주 잘못 알아듣습니다. 그래서 다음처럼 너그럽게 맞춰 봅니다.
  - 글자 단위로 비교하고, 비슷하게 들리는 소리(ㅈ·ㅉ·ㅊ, ㅐ·ㅔ, 받침 소리 등)에는 부분 점수를 줍니다.
  - 인식기가 낸 여러 후보 가운데 본문과 가장 잘 맞는 것을 씁니다.
  - 중간에 잘 안 들린 마디가 있어도 앞뒤가 맞으면 그 사이는 읽은 것으로 봅니다. 일부러 건너뛴 절은 치지 않습니다.
  - 엉뚱한 곳으로 잘못 넘어갔다가도 다시 읽는 곳을 찾아 돌아옵니다.
  - 상관없는 말(대화, 다른 본문)은 읽은 것으로 치지 않습니다.
- 인식 정확도는 `node tools/recognition_sim.js`로 잴 수 있습니다. 인식 오류를 흉내 내어 본문을 읽혀 보고, 얼마나 인정되는지 보여 줍니다.

## 본문

**개역한글판(1961)** 을 씁니다. 저작권 보호기간이 끝난 번역본입니다.
본문 데이터는 [thiagobodruk/bible](https://github.com/thiagobodruk/bible)의 `ko_krv`에서 가져와 `tools/build_data.py`로 권별 파일로 나누었습니다.
맥체인 읽기표(1842)는 [cwarloe/daily-bible-reading](https://github.com/cwarloe/daily-bible-reading)의 `mcheyne.json`을 `tools/build_mcheyne.py`로 옮겼습니다. 다른 자료와 대조했고, 모든 절이 구약 한 번·신약과 시편 두 번씩 빠짐없이 들어 있는지 검사로 확인합니다.
개역개정판은 대한성서공회의 저작물이라 넣지 않았습니다.

## 파일 구성

```
index.html            화면
css/style.css         디자인
js/app.js             날짜·읽기표·음성 인식·기록
js/matcher.js         인식한 말과 본문을 맞춰 보는 부분
js/plans.js           읽기표
js/books.js           66권 이름과 장별 절 수 (자동 생성)
js/mcheyne.js         맥체인 읽기표 365일 (자동 생성)
data/books/NN.js      권별 본문 (자동 생성, 그날 필요한 권만 불러옴)
sw.js, manifest.webmanifest, icons/   오프라인 저장과 홈 화면 추가
tests/                node --test 로 실행하는 검사
```

내 컴퓨터에서 확인할 때는 저장소 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`을 Chrome으로 엽니다. 검사는 `node --test`로 실행합니다.
